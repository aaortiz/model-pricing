Agentic Session Cost Model

Long agentic sessions are mostly cache reads, because every turn re-reads the conversation so far. Opus 5.5 charges the same for a cache read as Sonnet 5.5, so the longer a session runs, the smaller the price gap between them. Earlier Opus models never had this property.

    What this model can't show

    • Subscription plan limits. These are API prices, and plans may not scale exactly with API cost.
    • Tokens used per task. If one model finishes work in fewer tokens, that changes the real cost per task.
    • Output quality. The cost side of the argument stands on its own; the quality side needs other evidence.
    • Compaction and cache misses. The session builder assumes every turn reads the full cached history. Compacting a long session or missing the cache would change that. Use the token mix under Advanced options to add fresh input.
